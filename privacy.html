rkottomt.github.io and the "hw-outreach" tool · Last updated October 13, 2026

Who this covers

This is the personal website of Rohit Kottomtharayil. "hw-outreach" is a personal tool Rohit uses to prepare email drafts in his own Gmail account. It isn't offered to anyone else.

Google account data

hw-outreach asks Google for permission to compose Gmail messages, and uses it only to create drafts in Rohit's own mailbox. It doesn't read, send, delete or share anyone's email, and it doesn't use Google user data for advertising or sell it. Its use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Website

This site is static and hosted on GitHub Pages. It sets no cookies and runs no analytics. If you submit the contact form, your name, email and message are sent to Rohit only so he can reply.
