CODING AGENT SESSION: Building rohitkottomtharayil.github.io
Personal Portfolio Site — From Scratch to Fully Deployed
================================================================================

OVERVIEW
--------
Built a complete personal portfolio website for an ECE student at Carnegie Mellon
University using plain HTML, CSS, and vanilla JavaScript — no frameworks, no build
tools, deployable directly to GitHub Pages.

The session covered the full lifecycle: initial build, iterative design refinement
based on real-time user feedback, feature additions, bug fixes, and reversions.

TECH STACK
----------
- HTML5, CSS3 (pure custom), Vanilla JavaScript
- Google Fonts (Space Grotesk, Inter, JetBrains Mono)
- Zero dependencies — no npm, no build step
- Deployed via GitHub Pages

   - Tile click-to-flip: CSS 3D transform with personal labels on back

5. 5-PHASE CANVAS PARTICLE ENTRANCE ANIMATION
   The most complex feature — a 7-second choreographed animation:
   
   Phase 1 (0–0.7s): 16 grayscale particles bloom from center
   Phase 2 (0.7–2.8s): Particles orbit with neural-network constellation lines
   Phase 3 (2.8–4.4s): Tile slots glow, particles magnetically converge
   Phase 4 (4.4–5.4s): Impact shockwaves, canvas fades, tiles spring in
   Phase 5 (5.4–7s): Canvas fades to transparent, tiles settle
   
   - All particle physics driven by requestAnimationFrame with elapsed time
   - Grayscale palette (rgb 80 to rgb 255) matching B&W aesthetic
   - Neural network lines with midpoint nodes
   - Progress bar + replay button
   - Diagonal wave tile reveal (top-left to bottom-right)

6. SCROLL-DRIVEN 3D EFFECTS

   - 3D tilt on Selected Work cards (mouse-driven rotateX/rotateY)
   - Scroll-driven grid tilt (added then removed per user preference)
   - Exploded wireframe view (added then reverted per user preference)

7. CONTENT MANAGEMENT

================================================================================
NOTABLE TECHNICAL CHALLENGES SOLVED
================================================================================

1. CSS specificity conflict: Inline JS-set transforms blocked CSS class transitions.
   Fixed by clearing inline styles before adding transition classes.

2. Carousel wrap-around: Going from item 9→1 caused full 320° rotation instead
   of one step. Fixed by tracking cumulative angle instead of absolute index.

3. Browser caching: Users not seeing updates. Added ?v=N cache-busting query
   strings to all CSS/JS references.

4. Branch management: Changes made on feature branch while site deploys from main.
   Had to rebase, cherry-pick, and push directly to main multiple times.

5. Canvas particle animation: Coordinating 5 phases with different physics models
   (orbital, magnetic convergence, shockwaves) all driven by a single
   requestAnimationFrame loop with elapsed time branching.

================================================================================
DESIGN PHILOSOPHY
================================================================================

- Pure black, white, and grays — no color anywhere
- Architectural, precise, generative art aesthetic
- Engineering notebook meets design portfolio
- Every SVG pattern unique — no two tiles alike
- Smooth transitions everywhere (0.3s ease default)
- Spring/bounce cubic-bezier for interactive elements
- Film grain noise overlay at 3% opacity
- Monospace accents for labels, tags, and technical elements
